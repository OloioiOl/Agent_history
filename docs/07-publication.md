# GitHub 공개와 개인 운영 기록

## 공개본에 담은 것

구조, 실패 원인, 제한, 검증 범위, 축약 증거, 브리지 소스, fake 및 로컬 테스트. 운영 서버 주소, Discord 사용자·채널 식별자, 토큰, 인증 디렉터리 내용, 원문 문서, raw 모델 출력은 포함하지 않는다.

기존 서버용 설치·복구·활성화 스크립트는 특정 경로·UID·코드 해시에 의존하므로 공개 패키지에 복사하지 않았다. `bridge/`는 검토·테스트용 소스이며 즉시 설치 가능한 배포판이 아니다. `examples/`에는 가상 경로·계정의 systemd 유닛과 설정 키 예시를 제공하며, 실제 운영 설정으로 오해하지 않도록 전제와 미검증 범위를 적었다.

## 로컬 보존 원칙

원본 로그와 실제 문서는 이 저장소 밖의 비공개 위치에 둔다. `.gitignore`는 실수 방지 장치일 뿐 이미 추적한 비밀을 제거해 주지 않는다. 이 저장소에는 GitHub 원격 주소·토큰을 기록하지 않는다.

## 게시 상태

이 작업은 로컬 프로젝트 정리다. GitHub 저장소 생성, 원격 연결, push, 공개 게시를 수행하지 않았다. 공개 전에는 저장소 이름·가시성·코드 라이선스를 결정한다. 커밋 날짜를 과거 작업 시점처럼 소급하지 않는다.

## 나중에 추가할 자료

- 회고로 확보한 초기 중계 사례를 뒷받침하는 원문 전후 로그: 입력, 요청, 변형 결과. 로그가 없으면 관찰 회고로 유지.
- 정상 파일 운영 시험과 브리지↔Discord 답변 비교 결과.
- 검증 범위를 명시한 짧은 데모.
- 필요할 경우 독립 봇·opencode·보안 실습 환경의 별도 소스 및 근거.

서버 상태나 서비스 시작 시각은 지속적으로 변한다. 여기의 상태는 2026-10-08에 받은 출력 기준이며, 현재 상태 조회 도구를 대신하지 않는다.
