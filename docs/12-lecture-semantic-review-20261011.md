## 고정한 질문과 기준

실제 전달할 질문 전문은 비공개 `question.txt`에 고정했다. 다음 다섯 항목을 발췌만으로 설명하고 각 주장에 정확한 인용을 붙이도록 요청한다.

| ID | 평가할 내용 | 특히 구분할 것 |
|---|---|---|
| R1 | 타입 힌트 기반 검증·변환, 유효하지 않거나 누락된 값 | 강의 설명을 모든 타입 변환의 무조건 성공으로 확대하지 않기 |
| R2 | 사용자 정의 모델과 출력 파서 연결 | ‘입력’이라는 말 뒤의 ‘출력’ 정정 반영 |
| R3 | 파서 출력 지침을 프롬프트에 넣는 흐름 | 지침 제공과 모델의 준수 보장 구분 |
| R4 | 타이타닉 예제 요청과 모델에 따른 관찰 | 불명확한 자막, 실제 코드, 보편적 성능 주장을 구분 |
| R5 | 사실 정확성·명령 실행 안전성의 입증 범위 | 형식 검증을 정확성·안전성 보장으로 확대하지 않기 |

Codex가 5개 기준 주장과 해당 원문 인용을 작성했다. 이는 AI 보조 평가 초안이며, 실제 모델 응답이나 독립적인 사람의 정답 승인으로 세지 않는다. 기술의 최신 동작 검증이 아닌 **제공된 강의 문맥에 대한 충실도 평가**다. 자동 자막의 오인식은 인용에서 고치지 않고 해석의 불확실성으로 남긴다.

## 판정 방법

1. 실제 응답을 최소 주장 단위로 나눈다. 각 주장에 응답의 선택된 evidence와 판정 이유를 연결한다.
2. 파일·줄·문자열 일치와 의미 지지를 별도로 검사한다. 의미 판정은 **충분 / 부분 / 불지지 / 모순 / 판단유보**다.
3. 원문의 다른 줄에 사실이 있어도 선택된 인용이 주장 전체를 받치지 못하면 부분 지지로 남긴다. 여러 절을 한 주장에 묶어 누락을 숨기지 않는다.
4. 부재·입증 범위는 발췌 전체를 읽고 판단한다. 짧은 인용 하나가 보장 문구의 부재까지 증명한다고 보지 않는다.
5. 브리지 응답과 Hermes 최종 답변에 같은 기준을 각각 적용한다. 최종 답변의 누락·추가·정정 상실 및 인용 보존은 별도 기록한다.

승인 기준은 R1~R5 응답, 모든 핵심 주장의 충분한 인용 지지, 모순·근거 없는 추가·중요 누락 0건이다. 판단유보가 있으면 승인 보류한다. 전체 최소 주장 수와 판정별 개수를 보고하며, 위치 일치율을 의미 지지율로 대체하지 않는다. 사람의 승인 여부는 별도 필드로 유지한다.

## 다음 실행 범위

후속 대화에서 수업 교재가 계속 수정되는 Google 문서임을 확인했다. **[교재 수집 기반 마련 → 자막 연결 → 의미 평가](13-drive-material-collection-plan.md)** 순서로 진행한다. 아래 자막 단독 실행 제안은 보존하되 즉시 실행하지 않는다. 교재가 포함되면 입력·질문·해시를 별도 버전으로 확정하고 실행 범위를 다시 검토한다.
